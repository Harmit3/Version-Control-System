This folder contains the bonus part of the project.

To compile and run the program, run both commands below.

javac bug_commit_locate_bonus.java

java bug_commit_locate_bonus path-to-git-repo


Or, you can move the repository you want to test with to the bonus folder, then run both commands below.

javac bug_commit_locate_bonus.java

java bug_commit_locate_bonus name-of-repo
